# agent-sdk-typescript (`@abcp/agent-sdk`)

TypeScript SDK for the abc agent (`agent.v1.AgentService` +
`agent.v1.AdminService`) over Connect. **Generated code only**: the typed
messages + `AgentService`/`AdminService` descriptors are produced by `buf`
from `agent/v1/agent.proto`. Per the connectrpc convention the caller owns the
transport — build a `Transport` (`@connectrpc/connect-web` for browsers,
`@connectrpc/connect-node` for Node) and pass it to `createClient`.

It talks **only** to the agent; it does NOT deal with any gateway.

## Usage

```ts
import { createClient } from '@connectrpc/connect'
import { createConnectTransport } from '@connectrpc/connect-web'
import { AgentService } from '@abcp/agent-sdk'

const transport = createConnectTransport({
  baseUrl: 'https://agent.example.com',
  interceptors: [
    next => async req => {
      req.header.set('Authorization', `Bearer ${token}`)
      return next(req)
    },
  ],
})
const agent = createClient(AgentService, transport)
const r = await agent.health({})
```

For Node, swap `@connectrpc/connect-web` for `@connectrpc/connect-node` (it
handles HTTP/2 — cleartext h2c for `http://`, ALPN `h2` for `https://`).

## Regenerate

Generated by `abcp-sdk/agent-proto` (source of truth) and distributed here by
`agent-proto/scripts/sync-agent-sdks.sh`. **Do not edit `src/gen/` by hand.**

```bash
(cd ../agent-proto && ./scripts/sync-agent-sdks.sh --only ts)
npm run build
```

## Publishing

Consumed as a git dependency or a workspace link:

```json
"dependencies": {
  "@abcp/agent-sdk": "file:../agent-sdk-typescript"
}
```
