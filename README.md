# abcp-sdk agent-sdk-typescript

TypeScript SDK for the abc agent (`agent.v1.AgentService`). The typed RPC
client is generated by `buf` from `agent/v1/agent.proto`. This package adds
transport factories + bearer auth. It talks **only** to the agent; it does
NOT deal with easylab.

## Transports

Two transports, chosen by import path:

- **Web** (default, `@abcp/agent-sdk`): `fetch` + `@connectrpc/connect-web`.
  For browsers / SPA frontends.
- **Node** (`@abcp/agent-sdk/node`): `@connectrpc/connect-node`. Handles
  HTTP/2 only — cleartext h2c (prior knowledge) for `http://`, ALPN `h2` for
  `https://`.

## Usage

```ts
// Web (browser)
import { createAgentWebClient } from '@abcp/agent-sdk'
const agent = createAgentWebClient({ baseUrl: 'https://agent.example.com', token: 'devtoken' })
const r = await agent.health({})

// Node (h2/h2c)
import { createAgentNodeClient } from '@abcp/agent-sdk/node'
const agent = createAgentNodeClient({ baseUrl: 'http://abcp-agent:80', token: 'devtoken' })
```
